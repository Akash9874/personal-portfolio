# Akashdeep Dash — portfolio

Personal site for a full-stack and AI engineer in Bangalore. One page, black background, three 3D moments: a processor that pulls apart into the layers of the stack, a block of tools that breaks open, and sand that writes the sign-off.

## Run it

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production build in dist/
npm run preview   # serve the production build locally
```

## Deploy on Netlify

`netlify.toml` already sets the build command (`npm run build`) and the publish folder (`dist`), plus long-term caching for fonts and fingerprinted assets. Import this repository in Netlify and keep those defaults.

## Built with

Vite, Three.js, GSAP with ScrollTrigger and SplitText, Lenis, and React for the carousels.
